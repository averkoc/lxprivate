Instrumental only
Suno defaults to adding vocals if none are suppressed. When "instrumental only" is on, the renderer appends "instrumental only, no vocals, no lyrics" at the very end of the style prompt — recent testing on v5.5 suggests this trailing placement holds more reliably than leading with it.

0 words
Read before you paste. Suno hasn't published a strict prompt spec, so no attribute is guaranteed to land the same way twice. Longer prompts dilute the instructions that matter most — aim for 100–300 words, front-load genre → mood → instruments, and keep the "instrumental / no vocals" cue at the end of the Style field (also drop an [Instrumental] tag into the Lyrics field, or leave it blank). If Suno's preferred style shifts, only this renderer needs updating — not your saved projects.
